# Natural number

Natural numbers are the counting numbers: 0, 1, 2, 3, and so on, though some authors start at 1 and exclude 0. Both conventions are in use, and ISO 31-11 (1978) includes 0, while many older texts in number theory do not. The natural numbers are the building block from which integers, rationals, reals, and more elaborate number systems are constructed.

Two ideas sit behind the concept. Cardinality treats a number as the size of a collection, established by pairing elements one-to-one between two collections. Ordinality treats a number as a position in a sequence, the way the first, second, and third runners finish a race. The number 3 is simultaneously a size and a position, and the natural numbers are the simplest infinite set in which both views agree, a well-ordered set of order type ω, meaning every non-empty subset has a least element and the set has no largest element.

To remove the ambiguity about 0, "non-negative integers" means 0, 1, 2, … and "positive integers" means 1, 2, 3, …. The set is written ℕ, with ℕ₀ or ℕ₁ used when the inclusion of 0 must be explicit. "Whole numbers" is sometimes a synonym for non-negative integers and sometimes means all integers, so it is informal.

The intuitive idea is made precise in two ways. Peano's axioms, first sketched by Charles Sanders Peirce in 1881 and simplified by Giuseppe Peano in 1889, start from 0 and a successor function S that gives the next number, with rules: 0 is not a successor, different numbers have different successors, and any property true of 0 and preserved by S holds for every number. The last rule is mathematical induction. Set theory offers an alternative, the von Neumann construction, in which each number is a set: 0 is ∅, 1 is {0}, 2 is {0, 1}, and n is the set of every natural number below it. Both approaches describe the same numbers, but they answer philosophical questions about what numbers "are" differently. Certain results, such as Goodstein's theorem, are provable in ZFC set theory but not in Peano arithmetic, showing that no single axiomatization captures every truth about ℕ.

The arithmetic follows from counting. Addition and multiplication are defined recursively through S, so a + 0 = a, a + S(b) = S(a + b), a × 0 = 0, and a × S(b) = a × b + a. With addition, ℕ is a commutative monoid with identity 0; with multiplication restricted to the non-zero naturals ℕ*, it is a free commutative monoid with identity 1. Together (ℕ, +, ×) is a semiring, also called a rig, behaving like a ring except that no natural number has an additive inverse, since there is no n with n + 3 = 0. Division is therefore handled by Euclidean division: for any a and b with b non-zero, there are unique q and r with a = b×q + r and r < b.

The term "natural number" only became useful once negative, rational, and irrational numbers were discovered and a name was needed for the original ones. Hermann Grassmann's recursive definitions in the 1860s, Richard Dedekind's 1888 axiomatization, and Peano's cleaner 1889 version all aimed to put counting on a rigorous footing. Gottlob Frege's class-based definition ran into Russell's paradox, which forced the shift to defining each number as a specific set rather than a class. The French mathematician Nicolas Chuquet used *progression naturelle* around 1484 to describe the sequence 1, 2, 3, …, and the English phrase "natural number" first appeared in 1763.
