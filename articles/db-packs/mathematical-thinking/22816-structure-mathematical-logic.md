# Structure (mathematical logic)

In universal algebra and model theory, a *structure* is a set equipped with operations and relations that turn abstract symbols into concrete mathematics. It packages a domain (the set of elements), a signature (a vocabulary of symbols with declared arities), and an interpretation function (the rule assigning actual functions and relations on the domain to each symbol). Structures generalize familiar objects like groups, rings, fields, and graphs. From the model-theoretic view, they define the semantics of first-order logic: a sentence of a theory is either true or false in a structure, and a structure that satisfies every sentence is a *model* of that theory.

## Formal definition

A structure is a triple $\mathcal{A} = (A, \sigma, I)$ where:

- $A$ is the *domain*, an arbitrary nonempty set (classical first-order logic prohibits the empty domain).
- $\sigma = (S, \operatorname{ar})$ is the *signature*: a set $S$ of function and relation symbols with an arity function $\operatorname{ar}: S \to \mathbb{N}_0$ assigning each symbol a natural number of arguments.
- $I$ is the *interpretation function* that assigns to each $n$-ary function symbol $f$ an actual $n$-ary function $f^{\mathcal{A}} = I(f)$ on $A$, and to each $n$-ary relation symbol $R$ a relation $R^{\mathcal{A}} = I(R) \subseteq A^n$. A $0$-ary function symbol is a *constant symbol*, interpreted by a single distinguished element.

When context makes the interpretation clear, the same symbol is used for the symbol and its interpretation. A signature with only function symbols is called an *algebraic signature*, and a structure with such a signature is called an *algebra*.

## Worked example: fields

The standard signature for fields is $\sigma_f = (\{+,\times,-,0,1\}, \operatorname{ar}_f)$ with arities $+:2$, $\times:2$, $-:1$, $0:0$, $1:0$. The rationals, reals, complex numbers, and even the integers $\mathbb{Z}$ (which is not a field) all carry this signature as structures, with $+$, $\times$, $-$, $0$, $1$ interpreted in the obvious way. No field axioms are required for a set to be a $\sigma_f$-structure. An ordered field adds a relation such as $<$, so its structure is no longer an algebra. Set theory is captured by a signature with a single binary relation $\in$.

## Induced substructures

$\mathcal{A}$ is an *induced substructure* of $\mathcal{B}$ when they share the same signature, $|A| \subseteq |B|$, and every symbol is interpreted identically on $|A|$. A subset of $|A|$ is *closed* if every function of $\mathcal{A}$ maps it into itself; every subset has a smallest closed superset, its *hull*. The rationals are the smallest substructure of the reals satisfying the field axioms, while $\mathbb{Z}$ is the substructure generated by the empty set (not a field). Among the real numbers the corresponding algebraic notion is *subring*, not subfield.

For a graph encoded by one binary relation $E$ on a vertex set, induced substructures correspond to *induced subgraphs*, a stricter notion than ordinary subgraph: an edge in the whole graph remains an edge in any induced substructure that contains both endpoints.

## Homomorphisms and embeddings

A *homomorphism* $h: \mathcal{A} \to \mathcal{B}$ between structures of the same signature preserves every operation and every relation:
$$h(f(a_1,\ldots,a_n)) = f(h(a_1),\ldots,h(a_n)), \qquad (a_1,\ldots,a_n) \in R^{\mathcal{A}} \Rightarrow (h(a_1),\ldots,h(a_n)) \in R^{\mathcal{B}}$$

A *strong homomorphism* adds the converse implication for relations. An *embedding* is an injective strong homomorphism, so $(a_1,\ldots,a_n) \in R^{\mathcal{A}} \iff (h(a_1),\ldots,h(a_n)) \in R^{\mathcal{B}}$. Induced substructures correspond to subobjects in the category of embeddings; with only function symbols, embeddings coincide with monomorphisms.

The *homomorphism problem* (given two finite structures, decide whether a homomorphism exists) captures every constraint satisfaction problem, and conjunctive queries on relational databases reduce to the same problem, since a relational database is essentially a relational structure.

## Structures and first-order logic

A structure $\mathcal{M}$ has a *satisfaction relation* $\mathcal{M} \models \phi$ defined inductively via Tarski's T-schema, and is a *model* of a theory $T$ when every sentence of $T$ holds in $\mathcal{M}$. An $n$-ary relation $R$ on $|M|$ is *definable* when some formula $\varphi(x_1,\ldots,x_n)$ picks out exactly those tuples:
$$R = \{(a_1,\ldots,a_n) \in M^n : \mathcal{M} \models \varphi(a_1,\ldots,a_n)\}$$

A relation is *implicitly definable* when a formula in the language extended with a new symbol for $R$ singles it out as the unique relation satisfying it; by Beth's theorem, every implicitly definable relation is explicitly definable.

## Generalizations

A *many-sorted structure* has several domains, one per *sort* named in the signature, with arities given as tuples of sorts. Vector spaces fit naturally as a two-sorted structure with sorts $V$ (vectors) and $S$ (scalars) and scalar multiplication of type $(S, V; V)$. Universal algebra restricts axioms to universally quantified equations, which makes the choice of signature more significant than in model theory and leads to *partial algebras* when operations are undefined on part of the domain. In set theory and category theory the domain may be a *proper class* rather than a set, giving *class models*.
