# Determining the number of clusters in a data set

Many clustering algorithms (k-means, k-medoids, expectation-maximization) require the user to specify k, the number of clusters to find. Others, like DBSCAN and OPTICS, do not, and hierarchical clustering sidesteps the question. Choosing k is hard because increasing k always reduces error and reaches zero when k equals the number of points n, so naively maximising fit favours one cluster per point. The right k balances compression against accuracy, and several method families attempt to formalise that trade-off.

## The elbow method

The elbow method plots the percentage of variance explained against k and looks for the "elbow" where adding another cluster yields diminishing returns. The percentage of variance explained is the ratio of between-group variance to total variance, equivalent to an F-test. A variant plots the curvature of within-group variance instead. The idea traces to Robert L. Thorndike (1953). In practice the elbow is often ambiguous, the axes have arbitrary scale so an "angle" is not rigorously defined, and uniform random data can produce a false elbow. The method is therefore subjective and unreliable, and other methods tend to give better results.

## X-means clustering

X-means extends k-means by repeatedly attempting to split clusters and keeping the best splits until a stopping criterion such as the Akaike information criterion (AIC) or the Bayesian information criterion (BIC) is reached. Because k-means is "almost" a Gaussian mixture model, a likelihood can be constructed and used to evaluate information criteria automatically.

## Information-theoretic jump method

Rate distortion theory motivates the jump method, developed by Sugar and James. It runs a standard clustering algorithm for every k from 1 to n, computes the distortion of each clustering, and raises distortion to a negative power Y = p/2 (p is the data dimensionality). The k that maximises the jump J(k) = D[k] − D[k−1] in the transformed values is selected.

The distortion d_K is the minimum average Mahalanobis distance per dimension between each data point and its nearest cluster centre (Mahalanobis distance weights dimensions by the inverse covariance, so correlated or differently scaled features contribute appropriately). Asymptotic analysis (p → ∞) shows that, for a mixture of G Gaussian components, the transformed distortion stays near zero for K < G and then grows linearly once K ≥ G, producing a visible jump at the true number of clusters. A variant called the broken line method fits two line segments (one along the x-axis, one along the rising portion) and is more robust but assumes Gaussian components, whereas the jump method is non-parametric and works for general mixture distributions.

## Silhouette method

The silhouette of a data point measures how closely it matches its own cluster versus its nearest neighbouring cluster (the cluster with the lowest average distance). Values near 1 indicate a good fit, values near −1 suggest misassignment. Optimisation techniques such as genetic algorithms can search for the k that maximises the average silhouette, and rescaling the data can make the maximum align more reliably with the true cluster count.

## Cross-validation

The data is split into v parts; iteratively, one part is held out as a test set while the remaining v−1 parts train the model. The objective (for example, the sum of squared distances to centroids for k-means) is evaluated on the test set, averaged across the v folds for each k, and the smallest k whose further increase yields only a small reduction in objective is chosen.

## Specialised settings

For text databases clustered with the cover coefficient on an m×n document-by-term matrix with t non-zero entries, the number of clusters can be roughly estimated as mn/t, provided every row and column has at least one non-zero entry. Analysing the kernel matrix is another route: eigenvalue decomposition of the kernel (which encodes similarity in a higher-dimensional feature space) yields a compactness measure, and its elbow indicates k. Unlike most other methods, this approach does not require running a clustering algorithm first.

## Gap statistic

Tibshirani, Walther, and Hastie proposed the gap statistic, which compares the pooled within-cluster sum of squares against a null reference distribution generated by simulating data with the same marginal characteristics but no cluster structure. The optimal k is the one where the observed sum of squares falls farthest below the null expectation. A strength is that the gap can signal that no k produces a good clustering. Its reliability, however, depends on the plausibility of the null (typically uniform), and it struggles with datasets containing uninformative attributes because it treats all attributes as equally important. The method is implemented as `clusGap` in R's cluster package.
