# Constructible set (topology)

In topology and algebraic geometry, a **constructible set** is a subset of a topological space built from pieces of "simple" shape. The simple definition "finite union of locally closed sets" behaves badly on large non-Noetherian spaces, so a refined version using *retrocompact* opens is used in serious work. The central payoff is **Chevalley's theorem**: images of constructible sets under finitely presented morphisms are again constructible, which is why constructible sets are the natural language for describing fibres, images, and loci of geometric properties.

## What a constructible set is

A set is **locally closed** if it is the intersection of an open set and a closed set. A first definition says a constructible set is a finite union of locally closed subsets. This works in any locally Noetherian topological space (one in which every point has a Noetherian neighbourhood; this includes all algebraic varieties and most schemes of introductory algebraic geometry), and there it is equivalent to the refined definition below.

On a general topological space $X$, a subset $U$ is **retrocompact** if $U \cap K$ is compact for every compact open $K \subset X$. The standard definition (Élements de géométrie algébrique, first edition; Stacks Project) is:

> A subset of $X$ is **constructible** if it is a finite union of subsets of the form $U \cap (X - V)$, where $U$ and $V$ are open and retrocompact in $X$.

Equivalently, the constructible subsets of $X$ are the **Boolean algebra generated by the retrocompact open subsets**: the smallest family containing every retrocompact open set and closed under complement and finite union (and hence finite intersection).

A subset $Z \subset X$ is **locally constructible** if there is an open cover $(U_i)$ of $X$ such that $Z \cap U_i$ is constructible in $U_i$ for every $i$. The Stacks Project and EGA IV use this local notion; the second edition of EGA calls sets satisfying the boxed definition "globally constructible" and reserves "constructible" for the local version.

In any topological space, every constructible set contains a dense open subset of its closure.

## Chevalley's theorem

A morphism $f: X \to Y$ of schemes is **finitely presented** if $X$ can be built from $Y$ by gluing finitely many affine pieces, each described by finitely many equations. The fundamental result is:

> **Chevalley's theorem.** If $f: X \to Y$ is a finitely presented morphism of schemes and $Z \subset X$ is locally constructible, then $f(Z)$ is locally constructible in $Y$.

Images of schemes are not generally schemes: a polynomial map can send a variety to a set that is not itself a variety, yet still a constructible set. A concrete example is the morphism $\mathbf{A}^2 \to \mathbf{A}^2$ sending $(x, y)$ to $(x, xy)$. Its image is $\{x \neq 0\} \cup \{x = y = 0\}$, not a variety but constructible. The simplified "finite union of locally closed sets" definition does not preserve images in this generality, which is why the retrocompact refinement is used.

## Constructible loci of geometric properties

A recurring pattern in algebraic geometry: one wants to describe the locus where a geometric property holds, and that locus turns out to be locally constructible. The main source is EGA IV §9. Representative cases (all assuming a finitely presented morphism $f: X \to S$, and where stated, quasi-coherent sheaves) are:

- **Exactness of fibres.** For $\mathcal{F}' \to \mathcal{F} \to \mathcal{F}''$ a sequence of finitely presented quasi-coherent $\mathcal{O}_X$-modules, the set of $s$ for which the fibre sequence is exact is locally constructible.
- **Local freeness.** The set of $s$ for which the fibre $\mathcal{F}_s$ is locally free is locally constructible.
- **Relative closedness.** For a locally constructible $Z \subset X$, the set of $s$ for which $f^{-1}(s) \cap Z$ is closed (or open) in $f^{-1}(s)$ is locally constructible.
- **Morphism-level fibre properties.** For an $S$-morphism $f: X \to Y$, the set of $s$ for which the induced map $f_s: X_s \to Y_s$ is surjective, proper, finite, an immersion, a closed immersion, an open immersion, or an isomorphism is locally constructible.
- **Geometric fibre properties.** The set of $s$ for which the fibre $f^{-1}(s)$ is geometrically irreducible, geometrically connected, or geometrically reduced is locally constructible. (A fibre is "geometrically" $P$ if it stays $P$ after any field extension of the residue field.)
- **Pointwise fibre properties.** For a locally finitely presented $f: X \to S$, the set of $x \in X$ whose fibre $f^{-1}(f(x))$ is geometrically regular, normal, or reduced is locally constructible.

If, in addition, the morphisms involved are **flat** (the fibres vary continuously, with locally constant dimension), the locally constructible loci in these results are in fact open. EGA IV §12 develops this. So constructibility is the coarse layer, and flatness upgrades it to an open condition.

Constructible sets also feed into **constructible sheaves** and **intersection cohomology**, where the stratification of a space into constructible pieces controls how perverse and intersection cohomology theories are built.
