# Vector (mathematics)

A vector is a mathematical object that generalises a single number. Where a scalar records only magnitude (mass, temperature, time), a vector records magnitude together with a direction. Displacement, force, and velocity are the classic examples: a push of 10 newtons to the north is not the same object as a push of 10 newtons to the east, so each must be carried as a single directed quantity rather than a bare number.

Geometrically, a vector is drawn as a directed line segment: an arrow whose length encodes magnitude and whose orientation encodes direction. The same vector can be slid anywhere in space without changing its identity, because only direction and length matter, not its starting point. Adding two geometric vectors follows the parallelogram rule: place them tail to tail and the sum is the diagonal of the parallelogram they span. Multiplying a vector by a scalar stretches or shrinks it and, if the scalar is negative, reverses its direction. These two operations, addition and scaling, are the heart of the subject.

A more compact representation is a tuple, a finite ordered list of numbers. The tuple (3, 4) is the standard way to describe a vector in the plane whose horizontal component is 3 and whose vertical component is 4. Tuples are added and scaled component by component, which matches exactly what the parallelogram rule does in the picture. Tuples of length n, written ℝⁿ, form the standard coordinate vector space.

The fact that both geometric arrows and number lists support the same two operations, with the same algebraic behaviour, led mathematicians to abstract both into a single structure: a vector space. A vector space is a set together with vector addition and scalar multiplication that obey axioms generalising the arithmetic of arrows and tuples: associativity and commutativity of addition, a zero vector that acts as identity, additive inverses, and the distributive laws linking scalar multiplication with both operations. The axioms do not say what a vector is; they specify only how vectors must behave. Anything satisfying them is a vector space.

When the underlying set is geometric arrows, the resulting space is a Euclidean vector space; when it is ℝⁿ, it is a coordinate vector space. Many other sets satisfy the axioms too, including polynomial rings, function spaces, extension fields, and algebras over a field. By convention, the word "vector" is usually reserved for geometric arrows, tuples, and elements of an unspecified vector space being discussed in the abstract; elements of polynomial rings, function spaces, and similar constructions are typically given their own names instead.

Because tuples of numbers are so convenient, any data that can be represented naturally as a list of numbers tends to be called a vector, even when addition and scaling are not natural operations on the data. A probability vector is a tuple of non-negative numbers summing to one; a logical vector is a tuple of 0s and 1s representing Booleans; a random vector is a tuple of real-valued random variables that may be correlated. In some fields the word is stretched further: an interval vector in musical set theory records the intervallic content of a pitch-class set, and a Burgers vector in crystallography records the direction and magnitude of lattice distortion around a dislocation. In each case the data are representable as a list, and the familiar word is borrowed for it.

Calculus extends naturally to vectors in physics and engineering. A vector-valued function assigns a vector to each instant of time or each point in space, so it can describe the position, velocity, or acceleration of a moving object. Vector calculus generalises differentiation and integration to vector fields, which assign a vector to every point of a region. Three operators capture the local behaviour of such a field: the gradient measures how a scalar quantity changes in space, the divergence measures how a vector field spreads out from a point, and the curl measures how it circulates. Line integrals accumulate a vector field along a curve, which is how the work done by a force along a path is computed; surface integrals measure the flux of a vector field through a surface. These tools underpin electromagnetism, fluid dynamics, and continuum mechanics.

A few extensions refine the basic idea. Rotation vectors encode a rotation by giving its axis as a direction and its angle as a length, but they cannot represent every rotation globally, since a closed loop in rotation-vector space can correspond to a path in rotation space that fails to close; spinors were introduced to handle this shortcoming. Vector spaces can also be enriched with extra structure: a norm (producing a normed vector space, or in the infinite-dimensional case a Hilbert space), a partial order (an ordered vector space), a topology (a topological vector space), or a grading. These refinements make the axioms of a vector space precise enough to support analysis, geometry, and physics.
