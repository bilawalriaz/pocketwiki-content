# D (programming language)

D is a general-purpose, statically typed systems programming language with C-like syntax that compiles to native code. Walter Bright created it at Digital Mars and released it on 8 December 2001; Andrei Alexandrescu joined the design in 2007. D began as a re-engineering of C++ but is no longer source-compatible with it, though code legal in both C/C++ and D behaves the same. The D Language Foundation oversees development, and the compiler is open-source under the Boost License.

D keeps C++-style low-level control, including inline assembly for direct hardware access, and adds garbage collection, bounds-checked arrays, array slicing, closures, nested functions, compile-time function execution, design-by-contract, and uniform function call syntax. Type inference, function overloading, and operator overloading are built in. Strings are arrays of characters, and arrays carry runtime bounds checks.

The language spans five paradigms. Imperative code resembles C, with `foreach` for collection iteration. Object-oriented code uses single inheritance from a root `Object` class; reuse beyond that comes from Java-style interfaces and mixins, with no multiple inheritance. Functional features include function literals, closures, immutability, and library-supplied `map`, `filter`, and `reduce`. Concurrency and parallelism live in the standard library, using message passing through `std.concurrency` and parallel iteration through `std.parallelism.taskPool`; the type system detects shared data so the compiler can manage it. Metaprogramming combines imperative-style templates, `static if`, compile-time function execution, tuples, and string mixins that generate D source at build time.

Memory is usually managed by a garbage collector, but manual control is available through `malloc`/`free`, reference counting, scoped allocation, and custom allocator templates in `std.experimental.allocator`. By default, `struct` instances live on the stack and `class` instances on the heap; the `scope` keyword forces immediate destruction. SafeD marks functions `@safe` or `@trusted`, and the compiler then forbids pointer arithmetic and unchecked casts. `scope` and `return` annotations on parameters, codified in DIP25 and DIP1000, prevent references from outliving their targets inside `@safe` code.

D interoperates with C at the ABI level, so the C standard library is part of D's standard library, and bindings exist for C-based languages such as Python and Lua. With `extern(C++)`, D follows C++ name mangling and single-inheritance vtable layout, allowing direct calls to C++ classes. A restricted mode called Better C drops the D runtime, excluding the garbage collector, exceptions, built-in threading, and dynamic arrays, while keeping metaprogramming, modules, `scope(exit)`, and C++ interop. Supported platforms include FreeBSD, Linux, macOS, and Windows, with targets spanning x86, amd64, AArch64, PowerPC, MIPS64, and WebAssembly.

DMD is the reference compiler, LDC uses LLVM, and GDC merged into GCC 9 in October 2018. The `dub` build manager is standard, and D integrates with Visual Studio Code, Visual Studio, Eclipse, and Emacs. Users include Facebook, eBay, and Netflix, with applications in games, interpreters, an operating-system kernel, GPU code, web frameworks, numerical analysis, and machine learning. Version 1.0 shipped in January 2007; D2 followed in June 2007 and is now simply D. The current stable release is 2.112.1 (August 2026), and an OpenD fork was created on 1 January 2024.
