# Meta-learning (computer science)

Meta-learning, often called *learning to learn*, is a subfield of machine learning that applies automatic learning algorithms to metadata drawn from prior learning experiments. The aim is not to solve a single task well but to make the learning process itself flexible: either improving an existing algorithm on the fly or inducing the algorithm from experience. As of 2017 the term had no standard interpretation, but the practical goal is consistent, which is to let learning systems adapt faster and generalize further from new data.

Every learning algorithm carries an **inductive bias**, the built-in assumptions it makes about data, such as a preference for linear functions or for smaller hypotheses. A bias that matches the problem yields strong performance; a mismatch yields poor results. Meta-learning treats the choice of bias itself as something to be learned rather than fixed by the designer. Bias is split into *declarative bias* (the representation of the hypothesis space, for example restricting hypotheses to linear functions) and *procedural bias* (constraints on the order in which hypotheses are explored, for example preferring smaller ones).

A commonly cited definition requires three things of a meta-learning system. It must include a learning subsystem. It must gain experience from metadata extracted during a previous learning episode on a single dataset, or from metadata drawn across different domains. And it must choose its learning bias dynamically based on that experience.

The field clusters into three approaches. **Model-based** methods, such as Memory-Augmented Neural Networks and Meta Networks, use networks with external or internal memory so parameters update rapidly from a few examples. **Metric-based** methods, such as Siamese Networks, Matching Networks, and Prototypical Networks, learn a distance function over inputs so classification becomes a nearest-neighbor operation in the learned space. **Optimization-based** methods adjust the optimization procedure itself so a model learns well from very few examples; the leading example is Model-Agnostic Meta-Learning (MAML), introduced by Chelsea Finn and colleagues in 2017, which trains a model's parameters so that a few gradient steps on a new task produce good generalization on that task. MAML works with any model trained by gradient descent and has been applied to few-shot image classification and to policy-gradient reinforcement learning. Reptile is a simpler MAML-style algorithm.

Classical strategies treat metadata more directly and predate most neural approaches. *Discovering meta-knowledge* characterizes datasets and algorithms, then learns a mapping from data features to algorithm performance so the best learner for a new problem can be predicted. *Stacked generalization* trains several different algorithms and learns a combiner over their predictions. *Boosting* reuses a single algorithm multiple times with reweighted examples. *Dynamic bias selection* alters an algorithm's hypothesis space or heuristics to fit the problem. *Inductive transfer* applies knowledge from previous tasks to speed acquisition on new ones, the same idea behind the alternative name *learning to learn*.

A recurring idea runs through the earliest work. Schmidhuber's 1987 diploma thesis and Bengio and colleagues' 1991 paper on learning a synaptic rule established the principle of learning the learner. Schmidhuber showed in 1993 that self-referential recurrent neural networks can in principle learn their own weight-change algorithm. DeepMind extended this line in 2017, learning the optimizer itself by gradient descent. Meta Reinforcement Learning in Schmidhuber's group used self-modifying policies written in a universal programming language, in which an agent with a single lifelong trial continually improves its own learning algorithm to accelerate reward intake. The Gödel machine is the theoretical extreme of this line, a self-referential system with a general theorem prover that can provably optimally rewrite any part of its own software. AutoML systems, such as Google Brain's 2017 neural-architecture work, push the same idea toward automatically designed learners.

A practical limitation shapes most current methods. They optimize average performance across a task distribution, so individual tasks can be sacrificed for a higher mean. Robust Meta Reinforcement Learning (RoML) targets low-score tasks and can wrap other meta-learners such as MAML to improve their worst-case behavior. Variational Bayes-Adaptive Deep RL (VariBAD), introduced in 2019, is a model-based meta-RL method that uses a variational autoencoder to capture task information in memory and condition its decisions on the inferred task.
