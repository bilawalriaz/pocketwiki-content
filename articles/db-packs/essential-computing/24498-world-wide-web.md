# World Wide Web

The World Wide Web is an information layer that runs on top of the Internet, letting people fetch and link documents stored on computers anywhere in the world. It is not the same as the Internet: the Internet is the physical and logical network of machines, while the Web is one application that runs across that network and exchanges hyperlinked resources. It is the primary way billions of people interact with the Internet.

The Web rests on four interlocking pieces. **Documents** are written in HTML, a markup language that wraps text in tags describing structure (headings, paragraphs, links, images). **Addresses** use the Uniform Resource Locator (URL) scheme, which names both a resource and the machine that holds it. **Transfer** happens through HTTP, an application-layer protocol that runs on the Internet's transport layer; HTTPS adds encryption for sensitive traffic. **Clients** are web browsers, programs that resolve a URL to an IP address through the Domain Name System, send an HTTP request, and render the returned HTML together with its embedded images, stylesheets, and scripts.

To fetch a page such as `http://example.org/home.html`, the browser looks up `example.org` in DNS, opens a TCP connection on port 80 (or 443 for HTTPS), sends a short GET request, and receives an HTTP response whose body is HTML. The browser parses that HTML, fetches the referenced assets, and progressively renders the page. Embedded `<a href="...">` tags encode hyperlinks, the mechanism that turns isolated documents into a navigable web. A collection of related pages under a common domain name forms a **website**, hosted by one or more **web servers** that respond to HTTP requests.

The Web was invented in 1989 at CERN by Tim Berners-Lee, who proposed a "universal linked information system" to manage CERN's sprawling documentation. He had earlier built a private hypertext tool called ENQUIRE (1980) and was influenced by Ted Nelson's 1965 hypertext model. By late 1990 he had a working browser (WorldWideWeb) and HTTP server at CERN. The system spread to other research institutions in January 1991 and to the whole Internet on 23 August 1991, reaching 50 websites by 1993. CERN placed the protocol and code in the public domain on 30 April 1993, removing the licensing barrier that doomed a competing system called Gopher, which had begun charging fees in February 1993.

Growth accelerated after NCSA released the Mosaic browser later in 1993, the first graphical browser able to display inline images and submit forms. Marc Andreessen and Jim Clark founded Netscape in 1994, releasing Navigator with Java and JavaScript; its 1995 public offering helped trigger the dot-com bubble. Microsoft responded with Internet Explorer, bundled into Windows, and dominated the browser market for roughly 14 years in the so-called browser wars. Berners-Lee founded the World Wide Web Consortium (W3C) in 1994 to steward the protocol stack.

Two later standards fights reshaped the platform. W3C's stricter XHTML (1996) lost ground as developers exploited Internet Explorer's XMLHttpRequest object to build asynchronous Ajax applications, the technical foundation of the "Web 2.0" era around 2005. Mozilla, Opera, and Apple formed the WHATWG, which produced HTML5; W3C conceded in 2009 by abandoning XHTML, and in 2019 ceded control of the HTML specification to the WHATWG. Web pages today are typically built from the triad of HTML (content), CSS (presentation, encouraged by W3C since 1997), and JavaScript (behaviour, originally created by Brendan Eich at Netscape in 1995). Standards are maintained by W3C, WHATWG, the IETF, Ecma International, ISO, and the Unicode Consortium.

Persistent problems include cybercrime and privacy. Every unencrypted HTTP request exposes its destination to intermediate networks, so HTTPS and virtual private networks mitigate this by encrypting traffic and masking the originating IP address. State needed for logins and shopping carts is carried by HTTP cookies, small data tokens the server sets; third-party tracking cookies prompted European and US regulatory action beginning in 2011, and EU law now requires informed consent before storing non-essential cookies. Web pages have been measured to contain malicious code at roughly one in ten, and common attacks include phishing, cross-site scripting (XSS), and SQL injection, with defences such as browser sandboxing, the same-origin policy, and standardised cookie attributes.
