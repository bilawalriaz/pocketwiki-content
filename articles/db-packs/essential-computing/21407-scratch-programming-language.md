# Scratch (programming language)

Scratch is a block-based visual programming language and website aimed at children, primarily ages 8–16. Instead of typing text, users drag and snap together colorful blocks that represent commands. The blocks fit only in ways that form valid programs, making structure visible and removing the syntax errors that frustrate beginners in text-based languages.

The system was conceived at the MIT Media Lab by Mitchel Resnick and Yasmin Kafai through National Science Foundation grants and is now developed by the Scratch Foundation, which separated from MIT in 2019. It has been translated into more than 70 languages. As of February 2023, users had shared over 123 million projects, with the one billionth project reached on 12 April 2024.

## How a Scratch program works

A Scratch program runs on a **stage**, a coordinate-based area where 0,0 marks the center. The active objects are **sprites**, each drawn with the built-in vector or bitmap editor, chosen from a library, or uploaded. Every sprite carries its own scripts, costumes, and sounds.

Scratch is event-driven: scripts start when triggered, most often by clicking the green flag, by a key press, or by a broadcast message from another script. The language supports conditionals, loops, variables, one-dimensional lists, math and string operators, and user-defined functions that appear in a "My Blocks" category. Multiple scripts run at the same time, giving it a multi-threaded feel. It is deliberately limited: only one-dimensional arrays exist, string manipulation is weak, and procedures are not first-class values.

## Interface

The editor has three areas: a block palette, a coding area where blocks are assembled into scripts, and the stage. Standard block categories are Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, Lists, and My Blocks. An **Extensions** section adds Pen drawing, Music, Video Sensing, Text-to-Speech, Translation, and hardware control for micro:bit, LEGO Mindstorms, LEGO WeDo, and Makey Makey. An offline editor runs on Windows, macOS, ChromeOS, Android, and (unofficially) Linux.

## Community and sharing

The site is a social platform. Users called **Scratchers** upload projects that anyone can view, download, or **remix** into a new version; Scratch credits the original creator automatically. Projects are licensed under Creative Commons Attribution-ShareAlike, so derivatives stay open. Users organize work in **studios**, comment, favorite, or "love" projects, and follow one another. New accounts start as "New Scratcher" with restrictions, including no cloud data and a 30-second comment cooldown, then graduate to "Scratcher" after a period of activity. The Scratch Team, marked by an asterisk, are the official moderators.

In April 2020, the Tiobe index placed Scratch in the world's top 20 programming languages. It is used in schools, museums, libraries, community centers, and homes, appears in the first week of Harvard's CS50, and is taught in more than 800 schools and 70 colleges of India's DAV organization. The name comes from DJ "scratching," a metaphor for remixing media.

## History and versions

Scratch draws on Logo, Smalltalk, HyperCard, and AgentSheets. The prototype Scratch 0.1 appeared on 30 June 2003; the team slogan is "Imagine, Program, Share".

| Version | Released | Implementation |
|---------|----------|----------------|
| 1.x | 15 May 2007 | Squeak (Smalltalk-based) |
| 2.0 | 9 May 2013 | ActionScript (Flash) |
| 3.0 | 2 January 2019 | HTML5 and JavaScript, built on Google's Blockly library |

Scratch 3.0 replaced Flash after Adobe dropped support at the end of 2020 and added software-based extensions alongside hardware ones. Project files use `.sb3`, essentially a zip archive containing JSON plus `.wav` sounds and `.png` images; older versions used `.sb` and `.sb2`. In 2023 the site adopted purple headers and higher-contrast block colors to help colorblind users. Scratch has influenced Snap! (a Berkeley variant with first-class procedures and lists), mBlock, Catrobat, ScratchJr (a rewrite for ages 5–7), and TurtleStitch; open-source forks such as TurboWarp compile projects to JavaScript for faster execution. In August 2020, China blocked access to the site.
