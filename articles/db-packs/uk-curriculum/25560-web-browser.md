# Web browser

A web browser is an application that retrieves and displays web pages. When a user enters a Uniform Resource Locator (URL) such as https://en.wikipedia.org/ into the address bar, the browser acts as an HTTP client (also called a user agent): it fetches the page's files (HTML, style sheets, images, scripts) from a web server using the Hypertext Transfer Protocol (HTTP) or its encrypted variant HTTPS, then renders them into an interactive visual page.

The rendering engine (also called a layout engine) converts downloaded resources into the visible page. A separate JavaScript engine executes code that enables complex interactive applications. Browsers cache resources locally according to server-specified expiration rules, avoiding repeated downloads. A browser that does not render a graphical user interface is called a headless browser.

Web pages contain hyperlinks (URLs) that, when clicked, instruct the browser to load new resources. Browsers are not search engines. A search engine is a website that indexes and links to other sites; a browser is the tool used to reach that website. Most modern browsers merge the address bar with a search bar, blurring the distinction.

## History and market evolution

The first browser, WorldWideWeb, was created by Tim Berners-Lee in 1990. Mosaic (1993) introduced a graphical interface that made the Web accessible to non-technical users, triggering the 1990s Internet boom. Its developers founded Netscape, whose Navigator dominated until Microsoft bundled Internet Explorer with Windows as freeware, reaching over 95% share by the early 2000s.

In 1998 Netscape launched the Mozilla Foundation, producing Firefox (2004, peak 32% share in 2010). Apple released Safari in 2003, dominant on its devices. Google launched Chrome in 2008; it overtook Internet Explorer by 2012 and has led since. Microsoft replaced Internet Explorer with Edge in 2015, then rebuilt it on the open-source Chromium project in 2020. Since the mid-2020s, browsers with integrated AI chatbots (such as Chrome's Gemini, Edge's Copilot, and new entrants like Perplexity Comet) have emerged.

As of April 2025, Chrome holds ~63% global share, Safari ~17%, Edge ~7%, Firefox ~4%, with Samsung Internet, Opera, Brave, and others each at 1–2%. Chrome, Edge, Samsung Internet, Opera, and Brave share the open-source Chromium codebase; Safari uses Apple's WebKit; Firefox uses Mozilla's Gecko. Before late 2016 desktops generated most traffic; by February 2025 mobile devices accounted for 62%, desktops 36%, tablets 2%.

## Core features

Standard UI elements include tabs or windows for multiple pages, back/forward navigation, reload/stop, a home button, and a combined address/search bar. Mobile browsers simplify this UI for touch screens. Browsers automatically record history unless private mode is active, support bookmarks, extensions, download and password managers, and often sync data across devices. Desktop versions include sophisticated web development tools.

## DRM and media

Streaming services such as Netflix and Spotify protect content with Digital Rights Management (DRM). Browsers access this content via a Content Decryption Module (CDM) like Widevine. As of 2020, CDM licensing fees make DRM support impractical for most independent open-source browsers.

## Security and privacy

Browsers are frequent hacker targets. Vendors patch vulnerabilities regularly; users should keep browsers updated and use antivirus software. During browsing, sites store cookies (small data files that hold login credentials or preferences but also enable long-term tracking). Browsers provide cookie deletion; some block trackers and fingerprinting by default. Finer control usually requires extensions. Most browsers collect telemetry, typically opt-out. A 2020 study found privacy-focused browsers (Brave, DuckDuckGo, LibreWolf, Tor, Mullvad, Helium, Firefox Focus) outperformed mainstream browsers (Chrome, Firefox, Safari) largely because they block fingerprinting, tracking scripts, and ads by default.
