# Program (machine)

A **program** is a set of data or instructions that controls the behavior of a machine. The concept spans mechanical, electronic, and digital systems, unified by the idea that encoded information directs physical action.

## Mechanical origins

The earliest known programmable machine is a 9th-century automatic flute player built by the Banū Mūsā brothers in Baghdad. Their work was influenced by Hellenistic forebears but made significant improvements over Greek creations. The key contribution was the **pinned-barrel mechanism**—a rotating cylinder with protruding pins that lift levers to encode melody and rhythm, allowing the same device to play different tunes.

In 1206, Ismail al-Jazari in the Artuqid Sultanate described a programmable drum machine. By the 18th and 19th centuries, pinned barrels, **punched cards**, and **music rolls** directed player pianos, fairground organs, barrel organs, and music boxes.

The 1801 **Jacquard loom** applied punched cards to manufacturing: holes in each card represented specific loom arm movements, automating complex woven patterns. This demonstrated that discrete symbolic encoding could control intricate physical sequences.

## Electronic systems

In electronic systems, "program" often means user-adjustable parameters rather than authored code. Some programmable equipment only allows users to select predefined options or set predefined parameters; the user is not required or allowed to write a computer program.

A **programmable thermostat** stores a schedule of mode, time, and temperature settings. A **programmable synthesizer** holds a "patch" configuring module interconnections and parameter values. **Programmable ROM** stores fixed data for retrieval. **Programmable logic devices** store governance rules that the circuit follows during operation.

## Computer programs

A **computer program** (software) is a list of instructions executed by a computer, programmable calculator, or programmable logic controller. The processor fetches each instruction and alters the machine's state according to the instruction's predefined meaning.
