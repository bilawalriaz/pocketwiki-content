# Generator

A **generator** is any device, algorithm, or mathematical object that produces structured output from input. The term appears across engineering, computing, and mathematics with a shared logic: a source that yields a sequence, structure, or form of energy.

## Electrical and Mechanical Generators

An **electric generator** converts mechanical energy into electrical energy via electromagnetic induction. Mechanical input typically comes from a turbine driven by steam, water, wind, or combustion. This principle underlies nearly all grid-scale power production.

Related devices:
- **Engine-generator** (genset): an electric generator coupled to an engine, forming a self-contained power source for backup or portable use.
- **Tidal stream generator**: extracts kinetic energy from moving water masses—tidal currents or ocean streams.
- **Motor–generator**: converts electrical power from one form to another (e.g., AC to DC, or one frequency to another) without mechanical-to-electrical conversion.
- **Gas generator**: burns fuel to produce large volumes of relatively cool gas, often to drive a turbine rather than produce thrust directly.
- **Signal generator**: an electronic instrument that produces repeating or arbitrary waveforms for testing and calibrating circuits.
- **Generator (circuit theory)**: an idealized circuit element representing a voltage or current source in schematic analysis.

## Computing Generators

In computing, generators produce data or code on demand.

- **Generator (programming)**: a routine that yields a sequence of values one at a time, pausing between yields. Unlike a function that returns a complete collection, a generator maintains its internal state and resumes execution on each request. This enables memory-efficient processing of large or infinite sequences.
- **Pseudorandom number generator (PRNG)**: a deterministic algorithm that produces a sequence of numbers approximating randomness from an initial **seed** value. Identical seeds produce identical sequences, making PRNGs reproducible—essential for simulations and testing.
- **Code generator**: the compiler phase that translates an intermediate representation into target machine code or another lower-level language.
- **Application generator**: software that constructs application programs from high-level specifications rather than manual coding.
- **Natural-language generator**: converts structured machine representations (knowledge bases, logical forms) into human-readable text.
- **Random test generator**: automatically produces test inputs to exercise software paths.

## Mathematical Generators

In mathematics, a generator is a minimal element or set from which a larger structure can be built through the structure's operations.

- **Generating set of a group**: a subset such that every group element can be expressed as a finite combination (under the group operation) of elements from the subset and their inverses. A group with a single generator is **cyclic**.
- **Generating set of a module**: the module analogue—a subset from which all module elements are obtained via linear combinations with coefficients from the ring.
- **Generator matrix**: in coding theory, a matrix whose rows form a basis for a linear code. Multiplying a message vector by the generator matrix produces a codeword with added redundancy for error detection and correction.
- **Infinitesimal generator (stochastic processes)**: an operator describing the instantaneous rate of change of a continuous-time Markov process. It encodes transition rates between states and determines the process's evolution over infinitesimal time steps.
- **Generator (category theory)**: a family of objects in a category such that morphisms from this family collectively distinguish all other objects—serving as "probes" for the category's structure.

## Unifying Principle

Across every domain, a generator is defined by **production from input under constraint**. The input may be rotation, a seed, a specification, or a set of axioms. The constraint is the governing law—Maxwell's equations, an algorithm, a group operation, or a categorical diagram. The output is structured: alternating current, a deterministic sequence, machine code, a group element, or a codeword. The generator itself does not create ex nihilo; it transforms input into a form the surrounding system can consume.
