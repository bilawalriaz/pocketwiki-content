# Attention (machine learning)

Attention is a method for deciding how much each element in a sequence should rely on every other element when computing its representation. In modern neural networks this idea is implemented with "soft" weights: a vector of numbers between 0 and 1 that is recomputed for every input, in the forward pass only. By contrast, the "hard" weights of the network are learned once during training and stay fixed. Because soft weights change with every example, the same network can flexibly route information depending on context.

The core operation is **scaled dot-product attention**, introduced in the 2017 paper "Attention is All You Need" that proposed the Transformer architecture. For three matrices built from the input — a set of queries Q, a set of keys K, and a set of values V — the output is:

Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

Each row of QKᵀ measures how compatible a query is with each key. The softmax turns those scores into a probability distribution that sums to 1 across the keys, and the result is used to take a weighted average of the value vectors. The √dₖ factor in the denominator keeps the dot products from getting too large, which would otherwise make the softmax output a near one-hot vector (one entry close to 1, the rest near 0) and crush gradient flow. The output of each position is a linear combination of all the value vectors, restricted to lie inside the convex hull (the smallest filled polygon containing them) of the value rows.

A useful concrete example is the French translation of "I love you". On the first decoder step the model puts 94% of its attention weight on "I" and emits "je"; on the second it puts 88% on "you" and emits "t'"; on the third it puts 95% on "love" and emits "aime". Stacking the three soft weight vectors as rows gives an *alignment matrix* between source and target words, showing that the model has learned a many-to-many correspondence without explicit word-alignment supervision. Sometimes several source words contribute, as with the English "look it up" mapping to the single French "cherchez-le"; this is why soft weights outperform hard ones, where one weight would be set to 1 and the rest to 0.

Three properties explain why attention became dominant.

1. **Global reach in one step.** A recurrent neural network (RNN) processes a sequence token by token, so information from early tokens has to survive being passed through every hidden state, and the model tends to forget distant context. Attention lets every token look at every other token directly, so distance in the sequence no longer degrades access to information.

2. **Parallelism.** Because the attention output for each position is computed independently from the same set of keys and values, all positions can be processed at once on a GPU. RNNs, in contrast, are inherently sequential, and the 2017 Transformer paper showed that dropping recurrence in favour of attention made training much faster and more scalable.

3. **Permutation behaviour.** Reordering the key-value pairs leaves the output of an attention block unchanged for each query, because softmax over a permuted set returns a correspondingly permuted weight vector. The output is instead equivariant to reordering of the queries themselves. This symmetry lets the same attention code be reused on sets, on image patches, or on graph nodes without modification.

A practical issue is cost. The QKᵀ matrix has one entry per query-key pair, so memory and compute grow as O(n²) in the sequence length n. Implementations such as **FlashAttention** and Meta's **FlexAttention** address this by tiling the computation into small blocks that fit in fast on-chip GPU memory, trading memory for recomputation, and by allowing users to inject custom score modifications. Approximate variants such as Reformer, Linformer, and Performer push n² down to near-linear cost for very long sequences.

A few specialisations build on the base operation. **Multi-head attention** runs h attention computations in parallel, each with its own learned Q, K, and V matrices, then concatenates the results. Different heads can learn to look for different relationships, such as short-range versus long-range dependencies. **Masked attention** is used in autoregressive decoders, where the model generates output one token at a time and future tokens must not influence the current prediction; this is enforced by adding a strictly upper-triangular mask of −∞ values to the QKᵀ scores before softmax, so weights above the diagonal become 0. The result is a lower-triangular attention pattern in which position i may only attend to positions ≤ i. **Self-attention** is the case where Q, K, and V all come from the same sequence; the Transformer encoder and decoder both rely on it, with the decoder's self-attention requiring causal masking. **Cross-attention** connects a decoder to an encoder by using queries from the decoder and keys/values from the encoder. **Bahdanau (additive) attention** and **Luong (multiplicative) attention** are earlier forms, both still in use, in which the compatibility score is computed through a small feed-forward network or a learned bilinear form rather than a plain dot product.

After 2017 attention spread from machine translation to nearly every deep learning domain. Vision Transformers (ViTs) split an image into 16×16 patches, treat each patch as a token, and apply self-attention, achieving competitive image classification. AlphaFold 2 uses attention to reason over the amino acids in a protein, and CLIP uses it to align images and text. Attention also enabled architectures for graphs (Graph Attention Networks), for unordered sets (Set Transformers), and for long-range dependencies in video (Non-Local Neural Networks). The large language models BERT, T5, and the GPT family are all built from stacked Transformer blocks.
