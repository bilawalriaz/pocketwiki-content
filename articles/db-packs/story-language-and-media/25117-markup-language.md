# Markup language

A markup language is a text-encoding system that combines ordinary text with embedded instructions that specify a document's structure, formatting, and the relationships among its parts. The name comes from traditional publishing, where editors annotated paper manuscripts in red pen or blue pencil to tell typesetters which typeface, size, and style to apply.

Modern markup languages interleave plain text with tags written in angle brackets, such as `<h1>` for a heading or `<p>` for a paragraph. A program reading the document can apply its own formatting rules, so the same source can be rendered as HTML, PDF, or Rich Text Format. RecipeML demonstrates the pattern: a recipe file holds ingredients and steps as tagged elements, and separate software converts that structure into the desired output.

Three categories of markup are widely recognized, following work by Coombs, Renear, and DeRose in 1987. Presentational markup, used by traditional word processors, stores binary codes that produce WYSIWYG results and is hidden from users. Procedural markup embeds instructions that programs follow in sequence, as in troff, TeX, and Markdown, and is visible and directly edited. Descriptive markup labels what each piece of content is, such as a citation or paragraph, rather than how it should look. HTML's `<cite>` tag, which marks a citation without dictating appearance, is the classic example. Descriptive markup, also called semantic or logical markup, separates structure from presentation so that stylesheets or other processors decide how to render the content. The types overlap in practice: a word processor may save presentational markup in an XML-based descriptive format and process it procedurally, and TeX can host the descriptive LaTeX layer on top.

The history of markup languages in computing began with William Tunnicliffe's 1967 presentation of generic coding, a response to incompatible control notations in programs like RUNOFF. Brian Reid's 1980 doctoral thesis at Carnegie Mellon described Scribe, the first language to separate structure from presentation and to introduce stylesheets and a grammar controlling descriptive elements. Scribe influenced later systems and is an ancestor of both HTML and LaTeX.

Charles Goldfarb at IBM developed the underlying idea in 1969 and helped invent GML, deployed commercially in 1978. He chaired the ISO committee that produced SGML, released as ISO 8879 in October 1986. SGML is a metalanguage: it specifies how markup is written and, through a document type definition (later called a schema), which tags and attributes are permitted where. Authors can define their own tags while software verifies the result. SGML was powerful but cumbersome, partly because it allowed optional end tags to spare typing.

Tim Berners-Lee wrote a 1989 memo proposing an Internet-based hypertext system, then specified HTML and wrote the browser and server in late 1990. The first public description of HTML, "HTML Tags," appeared in late 1991 and listed 18 elements, most derived from SGMLguid, an internal CERN format. Eleven of those original elements survived into HTML 4. Berners-Lee treated HTML as an SGML application, and the IETF formalized this in mid-1993. HTML's reliance on descriptive markup was a major factor in the Web's success because it gave documents the flexibility to grow with the medium.

XML, the Extensible Markup Language, was developed by a W3C committee chaired by Jon Bosak to simplify SGML for Internet documents. XML kept SGML's extensibility and metalanguage properties while removing much of its complexity, and every XML document can also be written as a valid SGML document. Adoption was rapid because XML supported robust schemas and validation, and it is now used far beyond documents, including data exchange between applications, serializing program data, hardware protocols, and vector graphics.

From January 2000 until HTML 5, W3C recommendations for HTML were issued as XHTML, which required well-formed XML. XHTML enforced closed tags, quoted attribute values, and lowercase names, changes often criticized as verbose but praised for making errors easier to detect and repair.

Most markup languages embed tags inside the text stream, though standoff markup, where tags are stored separately and linked by pointers or offsets, is common in internal program representations. In HTML, semantic tags like `h1`, `p`, and `em` describe the purpose of content, while the older `<i>` tag was repurposed in HTML 5 to mean text in an alternate voice or mood, such as a taxonomic designation or a foreign phrase. Markup languages are now used for playlists, vector graphics, web services, content syndication, and user interfaces, and XML's extensibility lets multiple languages be combined in a single profile, as in XHTML+MathML+SVG.
