# Algorithmic learning theory

Algorithmic learning theory is a mathematical framework for analysing machine learning algorithms without relying on probability or statistics. It is also called formal learning theory or algorithmic inductive inference, and together with statistical learning theory it forms one of the two main branches of computational learning theory. The defining move is to drop the assumption that data are independent random samples, and to ask instead what an algorithm can provably learn from any sequence of inputs. This is a non-probabilistic version of statistical consistency, the requirement that a learner converge to a correct model in the limit; algorithmic learning theory demands convergence on every possible input sequence, not just on all but a zero-probability set. Most other frameworks restrict the learner more sharply, for example to polynomial-time algorithms, with probably approximately correct (PAC) learning as the leading case; algorithmic learning theory, by contrast, investigates the full power of Turing machines (abstract devices that can compute any program a real computer can run, given unlimited time and memory).

The central idea is **learning in the limit**. A learner is shown an endless sequence of data points, one at a time, and after each one it must output a hypothesis, its current best guess at the rule generating the data. From some step onward the hypothesis must stop changing, and the frozen final hypothesis must be correct for every data point, past and future. Because every possible input is required to appear somewhere in the sequence, a hypothesis that fits everything seen so far and never changes again will, in the limit, be correct everywhere. The learner is not required to recognise that it has finished; convergence is only visible to an outside observer.

E. Mark Gold introduced this notion in his 1967 paper "Language identification in the limit". The setting is language identification, where a "language" is any set of strings paired with a binary label, and the goal is for the learner to recover a Turing machine that decides the label of every string. At each step the teacher presents a string, and the learner outputs a program correct for all strings seen so far. The teacher eventually presents every possible string, in no fixed order. The learner has identified the language in the limit if, after some finite number of steps, its output program stops changing; that final program then decides the language everywhere.

Gold proved two key results. By enumeration, trying every possible Turing machine program in a fixed order and keeping the first that is consistent with all the data so far, the learner will eventually reach the true program and stay there, because the true program is one of those tried and is consistent with every future input. The cost is that enumeration can be arbitrarily slow, and the learner has no way of knowing when it has converged. The method shows that any language defined by a Turing machine program can be learned in the limit by a Turing-complete learner using only the data stream. Gold's second result limits this power: if the teacher provides only positive examples, strings that belong to the language and never any that do not, then only languages containing finitely many strings can be guaranteed to be learned in the limit. With an infinite language, the learner can never rule out some larger superset of the strings seen so far, and so cannot be forced to stop changing.

The framework ignores practical limits of runtime, memory, and noisy inputs, and gives no certificate that learning has succeeded, but its applicability is broad. Because the only constraint on the hypothesis class is computability (that a Turing machine can in principle carry it out), learning in the limit suits domains where observations are clean and structured rather than noisy and random, including natural-language grammar learning and automated scientific discovery from exact measurements.

Researchers have proposed alternative criteria that soften enumeration's brute-force character. Two of the most studied are efficiency, minimising the data required before convergence, and mind changes, minimising the number of hypothesis revisions before stabilisation. Mind-change bounds are closely related to mistake bounds in statistical learning theory, and Kevin Kelly has argued that minimising mind changes is a formal version of Occam's razor, since simpler hypotheses are reached sooner and held longer under enumeration.

The community meets annually at the International Conference on Algorithmic Learning Theory (ALT), held as a workshop from 1990 to 1997 and as a conference from 1998 onward, with proceedings in Springer's LNCS series between 1992 and 2016 and in the Proceedings of Machine Learning Research from 2017 onward. Its scope covers theoretical machine learning broadly, including online, active, and reinforcement learning as well as deep learning.
