# Hierarchical temporal memory

Hierarchical temporal memory (HTM) is a biologically constrained machine learning framework developed by Numenta, based on the physiology of pyramidal neurons in the mammalian neocortex. First described in Jeff Hawkins and Sandra Blakeslee's 2004 book *On Intelligence*, HTM stores, learns, infers, and recalls high-order sequences from unlabeled streaming data. It learns continuously without supervision, tolerates noise, holds multiple patterns at once, and is suited for prediction, anomaly detection, and classification.

## Core structure

An HTM network is a tree-shaped hierarchy of levels. Each level contains regions (nodes); higher levels usually hold fewer regions and store more general, longer-lasting concepts by combining patterns learned below. In inference mode, a region interprets the probabilistic output of its child regions as candidates for the categories it has memorised. The top level typically has a single region representing the most abstract, permanent concepts. An HTM level is not the same as one of the six anatomical layers of the neocortex.

Each region learns in two stages. *Spatial pooling* identifies frequently co-occurring input combinations and compresses them into a set of stored *coincidences*. *Temporal pooling* groups coincidences that tend to follow one another in the training sequence, so each group represents a likely cause of the input. During inference, the region computes a belief, the probability distribution over temporal groups, and passes it upward. Inputs that match the training sequence produce stable beliefs; unexpected inputs distribute probability nearly evenly across groups, signalling surprise. Higher levels therefore represent broader spans of space and time, mirroring the way larger concepts change more slowly than the smaller concepts they contain.

## Evolution of the algorithms

HTM is the algorithmic component of Hawkins's Thousand Brains Theory, and the model is revised as new cortical findings emerge. Three generations have appeared.

**Zeta 1 (first generation).** A region received a temporal stream of spatial patterns, identified recurring coincidences via spatial pooling, grouped them via temporal pooling, and output probabilities over temporal groups. Unexpected inputs yielded nearly equal probabilities across groups, and higher-level beliefs smoothed out short-term variation.

**Cortical learning algorithms (CLA, second generation).** CLA replaced zeta 1 with a more biologically realistic neuron model organised into layers of minicolumns, each containing roughly 20 cells. Activity is stored as sparse distributed representations (SDRs): binary vectors with a small fraction of bits active. Two components drive CLA. A spatial pooler keeps a fixed percentage of minicolumns active, and similar inputs activate a stable subset, so the representation is noise-tolerant. A sequence memory learns temporal transitions. Every cell is in one of three states at each step: active, inactive, or predictive. When a minicolumn becomes active, only its predictive cells fire; if none are predictive, all cells in the column activate. A cell becomes predictive by growing connections to nearby cells active over recent steps; when enough fire, it anticipates the next input. Active and predictive minicolumns both contribute to a layer's output, giving parent layers greater temporal stability. Learning and inference run together on every input, with no separate training phase, and predictions let the network fill in missing sequence elements and resolve ambiguous inputs. Numenta offers CLA commercially through Grok.

**Sensorimotor inference (third generation).** This generation adds the proposal that cortical columns at every level learn complete models of objects through movement, binding features to locations on object surfaces. It was expanded in 2018 as the Thousand Brains Theory.

## Neuron model and the cortex

The HTM neuron was inspired by neocortical pyramidal cells in layers 2/3 and 5. Like them, it carries thousands of synapses on active dendrites, where each dendritic segment acts as a coincident detector: co-activated synapses trigger an NMDA spike (a burst of electrical activity driven by NMDA receptors) and depolarise the soma (the cell body). Learning occurs by growing new synapses rather than adjusting weights as in a standard artificial neural network (ANN). HTM models only layers 2, 3, and 4 of cortex, uses strictly binary signals, has no direct inhibition of synapses or dendrites, and omits motor control (layer 5) and feedback between regions (layer 6 to layer 1). A typical HTM node corresponds to a group of about 80–100 real cortical columns.

## Sparse distributed representations

Conventional computers store information as dense patterns such as 32-bit words, in which every bit combination is meaningful. HTM uses SDRs instead. A typical implementation has 2048 columns and 64,000 cells, with around 40 active at any moment, giving roughly 2% sparsity, comparable to the fraction of neocortical neurons active at once. SDRs offer two main advantages. Because meaning is distributed across many bits, corrupting a few has little effect, whereas flipping one bit in a dense representation can change the entire meaning. And because similarity is encoded by overlap in active bits, the distance between two SDRs serves as a measure of semantic similarity. The semantic folding theory extends this idea, encoding words and texts as word-SDRs so that textual similarity can be computed by simple distance measures.

## Relationship to other models

HTM's tree of belief-passing nodes resembles a Bayesian network (a probabilistic graph that propagates beliefs between connected variables) with a fixed hierarchy, time-sensitive learning, and a mechanism for covert attention (internally focusing processing on one input stream while suppressing others). Like other ANNs, HTM is a hierarchy of simple units, but it models cortical columns with sparse, binary units rather than weighted neurons. Earlier related work includes LAMINART (Stephen Grossberg), HMAX for the visual ventral stream (Tomaso Poggio), and Fukushima's 1980s neocognitron, one of the first deep learning architectures. Tai Sing Lee and David Mumford earlier proposed a hierarchical Bayesian model of cortical computation, and HTM is broadly consistent with it while adding mechanisms for invariant representations in visual cortex.
