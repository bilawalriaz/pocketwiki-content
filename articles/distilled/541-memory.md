# Memory

## Overview
Memory is the faculty of the mind that encodes, stores, and retrieves information over time to influence future action; without it, language, relationships, and personal identity could not develop. It operates as an information processing system comprising a sensory processor, short-term (working) memory, and long-term memory, distinguishing between declarative (explicit) memory—conscious recall of facts and events—and non-declarative (implicit) memory—unconscious skills and priming. Memory is fallible: encoding, storage, and retrieval can be corrupted by pain, inattention, brain damage (especially to the hippocampus), and decay, while constructive processes during recall can introduce distortions such as the misinformation effect.

## Timeline
- **1904** — Richard Semon introduces the term "engram" for the physical trace of memory.
- **1956** — George A. Miller publishes "The Magical Number 7±2," establishing short-term memory capacity limits.
- **1963** — George Sperling uses the partial report paradigm to demonstrate sensory memory capacity (~12 items) and rapid decay.
- **1964** — Conrad shows short-term memory relies on an acoustic code (confusion of acoustically similar letters).
- **1966** — Baddeley discovers long-term memory encodes semantically (difficulty recalling words with similar meanings after delay).
- **1968** — Atkinson and Shiffrin propose the multi-store model (sensory → short-term → long-term via rehearsal).
- **1974** — Baddeley and Hitch propose the working memory model (central executive, phonological loop, visuospatial sketchpad).
- **1974** — Loftus and Palmer demonstrate the misinformation effect: question wording alters memory of an event.
- **1975** — John Meacham introduces the distinction between retrospective and prospective memory.
- **2000** — Baddeley adds the multimodal episodic buffer to the working memory model.
- **2015** — Consensus emerges that long-term memory requires gene transcription activation and de novo protein synthesis.
- **2022** — Review illuminates molecular mechanisms of DNA methylation/demethylation in long-term memory consolidation.

## Body

### Memory Architecture and Processes
Memory is modeled as a multi-stage system. **Sensory memory** holds raw perceptual input (iconic/visual, echoic/auditory, haptic/touch) for less than a second, is automatic, and cannot be prolonged by rehearsal. Sperling (1963) showed capacity is ~12 items but decays within hundreds of milliseconds. **Short-term memory** retains information for seconds to a minute without rehearsal; Miller (1956) estimated capacity at 7±2 items, though modern views suggest 4–5 items or a flexible information-based limit. **Chunking** (grouping digits into meaningful units) expands effective capacity. Short-term memory relies primarily on an acoustic code (Conrad, 1964). **Long-term memory** has vast, potentially lifelong capacity and encodes information semantically (Baddeley, 1966). The transition from short-term to long-term storage is **consolidation**, requiring the hippocampus (critical for learning new information, though not the storage site itself) and molecular processes including gene transcription, protein synthesis, and DNA methylation/demethylation. The multi-store model (Atkinson & Shiffrin, 1968) was criticized for oversimplification (e.g., rehearsal is not the only route to long-term storage; short-term memory has separable visual/acoustic components).

### Working Memory
Baddeley and Hitch (1974) replaced the unitary short-term store with **working memory**, an active maintenance system. It comprises: the **central executive** (attention controller routing information); the **phonological loop** (auditory rehearsal, subject to word-length effect, phonological similarity effect, and articulatory suppression); the **visuospatial sketchpad** (visual/spatial manipulation, absent in aphantasia); and the **episodic buffer** (added 2000, integrates cross-domain information into chronological units, links to long-term memory). Working memory explains dual-task performance (verbal + visual easier than two verbal) and underpins reasoning and learning.

### Types of Memory
**Declarative (explicit) memory** requires conscious recall: **semantic memory** (context-free facts, e.g., "Paris is the capital of France") and **episodic memory** (context-rich personal events, "what, when, where," including autobiographical memory). **Non-declarative (implicit) memory** operates unconsciously: **procedural memory** (motor skills like riding a bike, dependent on cerebellum/basal ganglia), **priming** (subliminal cueing of responses), and perceptual learning. **Retrospective memory** covers past knowledge (semantic, episodic, autobiographical); **prospective memory** covers future intentions (time- or event-cued, aided by external cues like lists). **Flashbulb memories** are vivid episodic memories of shocking public events (e.g., 9/11). **Topographical memory** supports spatial navigation.

### Physiology and Neural Basis
Key structures: **hippocampus** (spatial/declarative learning, consolidation, receives processed cortical input); **amygdala** (emotional memory enhancement—damage abolishes the effect); **prefrontal cortex** (working memory, source/temporal order/prospective memory); **cerebellum/basal ganglia** (procedural memory); **striatum, mammillary bodies**. Memory depends on synaptic plasticity: **long-term potentiation (LTP)** and **long-term depression**. **Engrams** (memory traces) are distributed across neocortical circuits. Consolidation involves **synaptic consolidation** (protein synthesis in medial temporal lobe) and **systems consolidation** (gradual MTL-independence over months/years). **Reconsolidation** renders retrieved memories labile and modifiable (misinformation effect, potential therapeutic weakening of traumatic memories). Glial cells play unresolved roles. Patient H.M. (Henry Molaison) initially suggested total hippocampal removal prevented new long-term memory; post-mortem revealed residual hippocampus, complicating interpretation.

### Molecular and Genetic Mechanisms
Long-term memory requires **de novo protein synthesis** and **gene transcription**. **DNA methylation/demethylation** bidirectionally regulates memory-promoting and memory-suppressor genes. In rats, contextual fear conditioning alters expression of ~1,500 hippocampal genes (9.17% of genome) at 24 hours, with methylation changes. **PKMζ** (autonomous PKC isoform) maintains synaptic strengthening; inhibition erases established long-term memories without affecting short-term memory or future encoding. **CREB** is a transcription factor critical for consolidation, downregulated in Alzheimer’s. **TOP2B** induces double-strand breaks in immediate early gene promoters during learning, enabling rapid transcription via NHEJ repair (DNA-PKcs, KU70/80, LIGASE IV). Epigenetic mechanisms (histone acetylation/methylation, DNA repair pathways) are central. **KIBRA** protein associates with forgetting rate; **APOE** links to Alzheimer’s memory dysfunction.

### Development, Aging, and Disorders
**Infancy**: Infants as young as 6 months show recall (deferred imitation), but **infantile amnesia** (accelerated forgetting) persists until hippocampal/frontal maturation (~9 months for temporal order). Rodent models implicate rapid brain growth; infantile amnesia is not unique to humans. **Aging**: Normal aging impairs frontal-dependent tasks (source memory, temporal order, prospective memory); gene expression for memory/learning declines after 40, sharply after 70, with oxidative DNA damage in promoters. **Disorders**: **Amnesia** from medial temporal lobe or diencephalic damage reveals subsystem functions. **Alzheimer’s** and **Parkinson’s** degrade memory/cognition. **Hyperthymesia** (inability to forget trivial details), **Korsakoff’s syndrome** (prefrontal neuron loss from thiamine deficiency), **anomic aphasia** (chronic tip-of-the-tongue). Viral infections (COVID-19, SARS, MERS, Ebola, influenza) can cause memory dysfunction.

### Influencing Factors
**Interference**: Retroactive (new learning impairs old) and proactive (old learning impairs new); **positive transfer** (e.g., Latin aiding French) counters this. **Stress**: Glucocorticoids/catecholamines impair hippocampal encoding; acute stress (cold pressor test) reduced free recall by 30%. **Context congruence** (same room/scent at encoding and retrieval) eliminates stress-induced impairment. Chronic stress damages CA1 hippocampal neurons via glutamate excitotoxicity; prenatal stress disrupts offspring hippocampal development and LTP. Socioeconomic memory gaps may reflect cumulative stress. **Sleep**: Enhances consolidation via hippocampal-neocortical replay during slow-wave sleep; deprivation impairs focus, retention, and can induce false memories. **Construction**: Memory is reconstructive, not reproductive. Loftus & Palmer (1974) showed post-event wording ("smashed" vs. "hit") alters speed estimates and creates false memories of broken glass (misinformation effect). Imagination inflation creates false autobiographical memories. Optogenetics in mice can implant false associations.

### Improving Memory
Lifestyle: intellectual activity, physical exercise (even light intensity, greatest benefit in youth), socialization, stress reduction, regular sleep, nutrition. **Mnemonics**: spacing effect (distributed rehearsal > cramming), Zeigarnik effect (uncompleted tasks remembered better), Method of loci (spatial encoding of non-spatial data). UCLA study (2008) showed 14-day "brain healthy" regimen improved word fluency, not memory; long-term effects unknown.

### Sex Differences
Meta-analysis shows small female advantage in cued/free recall; male advantage in complex span tasks; no difference in serial/simple span. Neuroimaging: males show greater lateral prefrontal, visual, parahippocampal, and cerebellar activity during long-term retrieval. Variance explained by task parameters; no publication bias detected.

### Plant Memory
Plants lack brains but exhibit memory-like functions. **Venus flytrap**: two trigger-hair stimulations within ~30 seconds required for closure; memory stored as cytoplasmic calcium summation reaching action-potential threshold (blockable by channel inhibitors). **Mimosa pudica**: habituation to repeated dropping (60 trials) persists one month, not due to fatigue (shaking restores response). Neurotransmitters and action potentials present, suggesting homologous mechanisms.

## Terms
- ****Chunking**** — Grouping individual items into larger, meaningful units to expand effective short-term memory capacity.
- ****Consolidation**** — The process stabilizing a memory trace after initial acquisition, transforming short-term into long-term memory via synaptic and systems-level changes.
- ****Declarative memory**** — Conscious, explicit memory for facts (semantic) and events (episodic); requires medial temporal lobe integrity.
- ****Engram**** — The enduring physical/chemical change in neural tissue that constitutes a memory trace (Semon, 1904).
- ****Episodic buffer**** — Working memory component (added 2000) integrating visual, spatial, verbal, and temporal information into unified episodes; links to long-term memory.
- ****Long-term potentiation (LTP)**** — Persistent strengthening of synapses based on recent activity patterns; a primary cellular mechanism for learning and memory.
- ****Misinformation effect**** — Distortion of memory by misleading post-event information, demonstrated by Loftus & Palmer (1974).
- ****Procedural memory**** — Implicit memory for skills and habits (e.g., riding a bike); depends on cerebellum and basal ganglia; difficult to verbalize.
- ****Reconsolidation**** — The process by which retrieved memories become labile and require restabilization, allowing updating or distortion.
- ****Working memory**** — Active maintenance and manipulation system (Baddeley & Hitch, 1974) replacing unitary short-term store; includes central executive, phonological loop, visuospatial sketchpad, episodic buffer.

## Debates and open questions
- **Consolidation mechanism**: Backpropagation (feedback error correction) is proposed (and used in AI by Hinton, Nobel laureate in Physics 2024) but lacks empirical neural evidence; positive feedback via neuroendocrine systems (arginine, nitric oxide, endorphins) has cross-species support but other mechanisms cannot be excluded.
- **Hippocampal role**: Patient H.M.’s post-mortem residual hippocampus challenges the classic view that total hippocampal removal is necessary for profound amnesia; the hippocampus may participate in consolidation for months/years rather than acting solely as a temporary gateway.
- **Reconsolidation validity**: Whether reconsolidation is a distinct, scientifically robust process or a retrieval/extinction phenomenon remains debated; strongly trained memories may resist reconsolidation initially but become susceptible later.
- **Memory storage locus**: While engrams are distributed, the precise neocortical circuits and the role of specific molecular tags (e.g., PKMζ persistence, DNA methylation patterns) in maintaining specific memories over a lifetime are unresolved.
- **Plant memory homology**: Whether plant calcium-based signaling and habituation constitute true memory analogous to animal neural memory, or merely physiological adaptation, remains controversial.
